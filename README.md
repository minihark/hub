# Harkco Hub (`hub.apps.harkco.se`)

> **Unified Tactile Fleet Launcher & Atelier for Harkco Daily Apps**  
> 100% Zero Ads • Zero Subscriptions • Direct Value Exchange • Gothenburg, Sweden

![Harkco Hub Preview](https://hub.apps.harkco.se/assets/index-DAxHZo7h.css)

## Overview
Harkco Hub is the centralized studio launcher showcasing all 12 tactile single-purpose web instruments created by Harkco Software Lab.

- **Live Fleet Telemetry**: Integrates with [Vakt](https://vakt.apps.harkco.se) to display live response latency (ms) and 100% operational uptime per app.
- **Fast Filter Tabs**: Filter across *Ekonomi & Skatt*, *Hantverk & Fritid*, *XRPL & Web3*, and *System & Spel*.
- **Instant Search**: Full-text fuzzy search with `⌘K` keyboard shortcut.
- **Tactile Audio Feedback**: Synthesized zero-dependency Web Audio clicks on launching and navigation.
- **Harkco Manifesto**: Outlines the studio's philosophy of craft, privacy, and direct monetization.

## The Harkco Fleet (12 Apps)
1. **SkatteKoll** (`skattekoll.apps.harkco.se`) — 3-Potters Princip for Swedish sole proprietorships & ABs (Private, Tax reserve, VAT).
2. **FakturaCraft** (`fakturacraft.apps.harkco.se`) — Swedish invoice generator on archive bond paper with OCR & ROT/RUT.
3. **Qvitt** (`qvitt.se`) — Group restaurant receipt scanning, live bill splitting & Swish integration.
4. **MötesKoll** (`moteskoll.apps.harkco.se`) — Swiss minimalist SEK meeting cost odometer & decision pad.
5. **Vakt** (`vakt.apps.harkco.se`) — Harkco fleet sentinel with JSON error extraction & Telegram alerting.
6. **Bryggkompis** (`brygg.apps.harkco.se`) — Craft brewery parchment notebook, strike water thermodynamics & priming sugar math.
7. **Styrka** (`styrka.apps.harkco.se`) — High-contrast gym chalk & iron logbook for 5x5 compound lifts.
8. **Akvarium** (`akvarium.apps.harkco.se`) — Sunlit Nordic natural history picture-book aquarium simulator & encyclopedia.
9. **Knattepatrullen** (`knatte.apps.harkco.se`) — 60fps 2D vehicle physics & learning adventure for 5-year-olds.
10. **Puls** (`puls.apps.harkco.se`) — Real-time XRPL consensus radar cockpit & acoustic whale detector.
11. **Knippa** (`knippa.apps.harkco.se`) — Batch transaction utility & aggregator for XRP Ledger.
12. **Time Capsule** (`time-capsule.apps.harkco.se`) — Encrypted future memory vaults & letters.

## Tech Stack
- **Frontend**: React 19, Vite 6, Tailwind CSS, Lucide Icons, Web Audio API
- **Backend**: Node.js 22 native HTTP + `sirv`
- **Deployment**: Docker on OrbStack `cloud-local`, Traefik reverse proxy, Let's Encrypt TLS
